# 건축소사무소 웹사이트

React와 NestJS를 사용한 건축소사무소 웹사이트 프로젝트입니다.

## 프로젝트 구조

- `packages/frontend`: React 프론트엔드
- `packages/backend`: NestJS 백엔드
- `packages/shared`: 공유 타입 및 유틸리티

## 시작하기

```bash
# 의존성 설치
yarn install

# 개발 서버 실행 (프론트엔드 + 백엔드)
yarn start

# 프론트엔드만 실행
yarn start:frontend

# 백엔드만 실행
yarn start:backend
```
